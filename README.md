# Kayley

一人法人・個人事業主のための、売掛金・家賃光熱費の個人負担按分・役員報酬を毎月記録し、税理士さんへの月次報告をPDFで出力するための、完全ブラウザ完結型の小さな帳簿アプリです。

- サーバー不要・インストール不要。データはすべて**あなたの手元だけ**に保存されます（外部には一切送信されません）。
- 保存には SQLite (WASM) を使用します。デスクトップアプリ版はアプリ専用フォルダ内の実ファイルに、ブラウザで直接動かす場合はブラウザの OPFS（対応ブラウザ）または IndexedDB に永続化します。
- 月次レポート画面からブラウザの印刷機能でPDFに出力できます。

## デスクトップアプリ版（推奨・非エンジニア向け）

ブラウザやコマンドラインを意識せず使えるよう、Mac / Windows それぞれのアプリとしても配布できます（Electronでラップし、中でこのフォルダをローカルサーバーとして起動するだけで、アプリ自体の中身・データ保存先はブラウザ版と同じです）。

- **Mac**: `dist/Kayley-1.0.0-arm64-mac.zip`（Apple Silicon）または `dist/Kayley-1.0.0-mac.zip`（Intel）を解凍し、`Kayley.app` を「アプリケーション」フォルダへドラッグ。初回起動時は未署名アプリのため「開発元が未確認」の警告が出るので、Finderで**右クリック→「開く」**を選んでください（2回目以降は通常のダブルクリックで起動できます）。
- **Windows**: `dist/Kayley-1.0.0-win-x64-portable.zip` を解凍し、フォルダ内の `Kayley.exe` を実行してください。未署名のため SmartScreen の警告が出る場合は「詳細情報」→「実行」を選びます。デスクトップ・スタートメニューへのショートカット付きの通常のインストーラー（`.exe` セットアップ）は、実際の Windows か GitHub Actions 等のx64環境でしか生成できない都合上、現状はこの「解凍して実行」形式のみです。

ビルドし直す場合（要 Node.js）:

```bash
npm install
npm run dist:mac   # Mac向け（zip）
npm run dist:win   # Windows向け（NSISインストーラー。x64環境で実行すること）
```

アプリ版とブラウザ版でデータは自動的には共有されません（Electron内は別のブラウザプロファイル扱いのため）。乗り換える場合は、今お使いの環境の「設定」タブから「.sqliteをエクスポート」→ アプリ版の「設定」タブで「.sqliteをインポート」してください。同じ手順で、ローカルファイル保存に対応する前の古いバージョンのアプリから乗り換える場合も一度だけ移行が必要です。

## 使い方（開発者向け・ブラウザで直接動かす場合）

ES モジュールと WASM ファイルの読み込みには `file://` ではなく HTTP 経由での配信が必要です（ブラウザのセキュリティ制限のため、index.html をダブルクリックするだけでは動きません）。下記のどちらかで、このフォルダをルートにした簡易サーバーを起動してください。

```bash
# Python が入っている場合
python3 -m http.server 8000

# Node が入っている場合（インストール不要）
npx serve .
```

起動したら、ブラウザで `http://localhost:8000`（または表示されたポート）を開きます。

初回起動後は「設定」タブで会社名・創業年月・会計年度開始月・光熱費個人負担率のデフォルトを入力し、「売掛金」タブで得意先を登録してください。

## 画面構成

| タブ | 内容 |
|---|---|
| ダッシュボード | 当月のスナップショットと直近12ヶ月の推移 |
| 売掛金 | 得意先ごとの当月売上・入金、残高は自動繰り越し計算。休止した得意先も実績のある月では表示されます |
| 家賃・光熱費 | 家賃実額と個人負担固定額、光熱費の全体額と個人負担率から個人負担額を自動計算 |
| 役員報酬 | 支給額・保険料等を入力。家賃・光熱費の個人負担額は**前月分**が自動的に控除項目として反映されます（実績確定が翌月になるため） |
| 月次レポート | 上記3点＋証憑（領収書・請求書）をまとめた印刷用ページ。「この月をPDF出力」→ブラウザの印刷ダイアログで「PDFに保存」 |
| 設定 | 会社情報、創業年月、得意先の管理、外観、バックアップ |

各月は「確定」スタンプで確定状態にできます（データを変更不可にするものではなく、入力が終わったことを示す目印です）。

## 一括入力（年度まとめて）

売掛金・家賃光熱費・役員報酬の各タブには「📋 一括入力（年度）」ボタンがあり、1年度分を表形式でまとめて入力できます。

- 年度は「第N期」表示付きのプルダウン、または矢印で切り替え（創業年月より前には遡れません）
- Excel・Googleスプレッドシートで範囲コピーした内容を、貼り付け先のセルを起点にそのまま流し込めます（カンマや円マーク付きの数値も自動で認識）

## 証憑（領収書・請求書）の保存

「経費」タブ・「売掛金」タブから、設定不要でそのまま領収書・請求書をアップロードできます。ファイルの実体はデスクトップアプリのユーザーデータフォルダ内（`attachments/`）に保存されます。「.sqliteをエクスポート」にはデータベースの内容のみが含まれ、添付ファイルの実体は含まれない点に注意してください。

## 外観のカスタマイズ

「設定」タブで背景色・カードの色・文字色・背景パターン・背景画像を自由に変更できます。コントラストチェック（Colorableと同じ考え方）付きのランダム配色や、お気に入りの保存にも対応しています。

## データのバックアップ・他のPCへの移行

「設定」タブの「.sqliteをエクスポート」でデータベースファイルを1つのファイルとして書き出せます。別のPC・別のブラウザで「.sqliteをインポート」すれば、そのまま続きが使えます。定期的なバックアップをおすすめします。

## 技術構成

- ビルドステップなし。素の HTML / CSS / JavaScript（ESモジュール）。
- [sql.js](https://github.com/sql-js/sql.js)（SQLite の WebAssembly 版）を `vendor/` に同梱。
- チャートは外部ライブラリ無し、軽量な自前の SVG 実装（`js/charts.js`）。
- フォントは Google Fonts の Shippori Mincho / Zen Kaku Gothic New / JetBrains Mono を使用（オフラインの場合はシステムフォントにフォールバックします）。
- デスクトップアプリ版は `electron/` 配下（`main.js` がウィンドウ生成とIPCハンドラ、`preload.js` がレンダラーに保存用APIを公開、`server.js` がアプリ本体と添付ファイルを配信するローカル専用HTTPサーバー）。アプリ本体（`js/`・`css/`・`vendor/`）は一切変更せずそのまま同梱しているだけです。データベース・添付ファイルの実体はOSのユーザーデータフォルダ内に保存されます。

## 他の会社・他の人が使う場合

このリポジトリをそのまま clone/download すれば、それぞれ自分のブラウザに独立したデータを持てます（データは共有されません）。得意先名・会社名などは「設定」「売掛金」タブから自由に登録し直してください。
