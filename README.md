# 月次伝票 (Geppyo)

売掛金・家賃光熱費の個人負担按分・役員報酬を毎月記録し、税理士さんへの月次報告をPDFで出力するための、完全ブラウザ完結型の小さな帳簿アプリです。

- サーバー不要・インストール不要。データはすべて**あなたのブラウザの中だけ**に保存されます（外部には一切送信されません）。
- 保存には SQLite (WASM) を使用し、ブラウザの OPFS（対応ブラウザ）または IndexedDB に永続化します。
- 月次レポート画面からブラウザの印刷機能でPDFに出力できます。

## 使い方

ES モジュールと WASM ファイルの読み込みには `file://` ではなく HTTP 経由での配信が必要です（ブラウザのセキュリティ制限のため、index.html をダブルクリックするだけでは動きません）。下記のどちらかで、このフォルダをルートにした簡易サーバーを起動してください。

```bash
# Python が入っている場合
python3 -m http.server 8000

# Node が入っている場合（インストール不要）
npx serve .
```

起動したら、ブラウザで `http://localhost:8000`（または表示されたポート）を開きます。

初回起動後は「設定」タブで会社名・会計年度開始月・光熱費個人負担率のデフォルトを入力し、「売掛金」タブで得意先を登録してください。

## 画面構成

| タブ | 内容 |
|---|---|
| ダッシュボード | 当月のスナップショットと直近12ヶ月の推移 |
| 売掛金 | 得意先ごとの当月売上・入金、残高は自動繰り越し計算 |
| 家賃・光熱費 | 家賃実額と個人負担固定額、光熱費の全体額と個人負担率から個人負担額を自動計算 |
| 役員報酬 | 支給額・保険料等を入力。家賃・光熱費の個人負担額は**前月分**が自動的に控除項目として反映されます（実績確定が翌月になるため） |
| 月次レポート | 上記3点をまとめた印刷用ページ。「この月をPDF出力」→ブラウザの印刷ダイアログで「PDFに保存」 |
| 設定 | 会社情報、得意先の管理、バックアップ（.sqliteのエクスポート／インポート） |

各月は「確定」スタンプで確定状態にできます（データを変更不可にするものではなく、入力が終わったことを示す目印です）。

## データのバックアップ・他のPCへの移行

「設定」タブの「.sqliteをエクスポート」でデータベースファイルを1つのファイルとして書き出せます。別のPC・別のブラウザで「.sqliteをインポート」すれば、そのまま続きが使えます。定期的なバックアップをおすすめします。

## 技術構成

- ビルドステップなし。素の HTML / CSS / JavaScript（ESモジュール）。
- [sql.js](https://github.com/sql-js/sql.js)（SQLite の WebAssembly 版）を `vendor/` に同梱。
- チャートは外部ライブラリ無し、軽量な自前の SVG 実装（`js/charts.js`）。
- フォントは Google Fonts の Shippori Mincho / Zen Kaku Gothic New / JetBrains Mono を使用（オフラインの場合はシステムフォントにフォールバックします）。

## 他の会社・他の人が使う場合

このリポジトリをそのまま clone/download すれば、それぞれ自分のブラウザに独立したデータを持てます（データは共有されません）。得意先名・会社名などは「設定」「売掛金」タブから自由に登録し直してください。
